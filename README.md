## 🎯 功能特性

- **断点续做**：意外关闭页面可无缝恢复进度
- **智能计分**：多选题 0.5 分制（选对1个得0.5，有错选得0分）
- **逐题解析**：每题附教材原文、知识点速览、选项精析
- **错题重做**：完成后可针对错题单独强化训练
- **进度可视化**：实时得分 + 轮次历史追踪

---

## 🚀 使用方法

1. 直接双击 `index.html` 在浏览器中打开即可。
2. 选择已上线的章节开始练习
3. 每题选择答案后点击"确定"，查看解析
4. 完成后点击"错题重做"或"重新全量练习"
